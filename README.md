# F# Recursive Descent Parser

## Overview

A recursive descent parser implemented in F# to validate source code against a formal grammar defined using Backus-Naur Form (BNF).

This project explores functional programming principles, including recursion, pattern matching, immutable data structures, and syntax analysis.

## Technologies

- F# 10.0
- .NET 10
- F# Interactive (FSI)
- Visual Studio Code
- Git and GitHub

## Getting Started

### Prerequisites

- .NET 10 SDK

### Running the Parser

```bash
dotnet fsi nclemen1.fsx
```

Enter an input string when prompted.
